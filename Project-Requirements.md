# Afghanistan Pre-Owned Clothing Marketplace
## Project Requirements Document
### 1. Project Introduction
The Afghanistan Pre-Owned Clothing Marketplace is a web-based platform designed to help people in Afghanistan buy and sell pre-owned clothing online. Users will be able to create an account, post clothing items they no longer use by adding pictures, descriptions, sizes, conditions, and prices, and browse available items posted by other users.
The main purpose of this project is to provide a simple and convenient way for people to sell clothes they no longer need and for other people to find affordable pre-owned clothing.
