## Meeting Purpose

The purpose of this meeting was to officially plan Sprint 2, review the selected Product Backlog items, confirm the Sprint goal, discuss frontend and backend responsibilities, and agree on the Sprint schedule.

## Selected User Stories and Requirements

### US-005: Search for Clothes – 5 Story Points

Users should be able to search for clothing items using a name or keyword.

The system should display matching products and provide an appropriate result when no matching clothing item is found.

**Planned Work:**
- Frontend search interface
- Backend search functionality
- Connect search results with product data

---

### US-006: Size and Price Filters – 5 Story Points

Users should be able to filter clothing items based on size and price.

The system should display products that match the selected filter options.

**Planned Work:**
- Frontend filter controls
- Size filtering
- Price filtering
- Backend filtering logic
- Integration with clothing listings

---

### US-007: Clothing Condition – 3 Story Points

The clothing condition should be available as part of the product information.

Examples include:

- New
- Like New
- Good
- Used

The selected condition should be visible with the clothing listing.

**Planned Work:**
- Clothing condition option in the frontend
- Store the selected condition
- Display clothing condition with product information

---

### US-008: Upload Product Photos – 5 Story Points

Sellers should be able to upload a valid photo when creating a clothing listing.

The uploaded photo should be connected to the listing and displayed correctly on the website.

**Planned Work:**
- Product photo upload interface
- Photo handling in the backend
- Connect uploaded photos with clothing listings
- Display product photos correctly

---

### US-009: Product Information – 5 Story Points

Sellers should provide the necessary information about clothing before publishing a listing.

The main product information includes:

- Price
- Size
- Condition
- Description

**Planned Work:**
- Product information form
- Save product information
- Retrieve product information from the database
- Display product information correctly on the website

---

### NFR-002: Performance – 5 Story Points

The team will continue improving the website performance so the main pages and features work smoothly during normal use.

---

### NFR-003: Input Validation – 5 Story Points

The system should check required information before accepting a clothing listing.

Validation will include required fields and product information entered by the user.
