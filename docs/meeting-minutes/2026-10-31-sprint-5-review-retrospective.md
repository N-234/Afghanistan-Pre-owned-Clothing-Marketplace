# Sprint Review

## 🎯 Sprint 5 Goal

The main goal of Sprint 5 was to improve the overall quality, accessibility, usability, and responsiveness of the marketplace.

The Sprint 5 work included:

- US-019 – Notifications
- US-020 – Mobile and Desktop Support
- ENHANCE-001 – Improve Product Image Loading and Display
- ENHANCE-002 – Add Sorting Options for Clothing Listings
- ENHANCE-003 – Improve the Mobile User Interface
- NFR-006 – Browser Compatibility
- NFR-007 – Maintainability

A total of **32 Story Points** were planned for Sprint 5.

---

## 💻 Sprint 5 Demonstration

Parwana shared her screen and demonstrated the completed Sprint 5 work.

### 👩‍💻 Notifications

The team demonstrated the notification feature.

The system now shows a notification bell with the number of unread messages.

When a user receives a new message:

- A notification appears
- The user can click the notification
- The user is taken directly to the Inbox
- The latest message can be viewed

This completed the planned notification functionality.

---

### 📱 Mobile and Desktop Support

The team demonstrated how the marketplace works on different screen sizes.

The website was checked in:

- Desktop view
- Mobile view
- Tablet view

The navigation bar, search, filters, buttons, and main pages were adjusted so they work correctly on smaller screens.

The team also improved the mobile layout so the website remains easy to use on different devices.

---

### 🖼️ Product Image Improvements

The team improved how clothing images are displayed.

Because uploaded product images can have different sizes, the display was adjusted so images appear more consistent and properly positioned.

The images now:

- Display clearly
- Keep a consistent layout
- Fit better inside product cards
- Work properly on different screen sizes

---

### 🔃 Sorting Options

Sorting options were added for clothing listings.

Users can sort listings by:

- Newest first
- Oldest first
- Price: Low to High
- Price: High to Low

The team demonstrated that the listings update correctly based on the selected sorting option.

---

### 🛠️ Additional System Improvements

The team also demonstrated several improvements to previously completed functionality.

These included:

- Improved administrator dashboard
- Report management
- User management
- Listing management
- Administrator-only access
- Ability for administrators to create other administrator accounts
- Improved buttons and interface elements

The team confirmed that these improvements were integrated with the existing system.

# Sprint Retrospective

## 🎯 Retrospective Purpose

Because Sprint 5 was the final development Sprint, the Retrospective focused on the team's experience during Sprint 5 and throughout the whole project.

The discussion included:

- What was challenging
- What the team learned
- How the team worked together
- The overall project experience

---

## 👩‍💻 Parwana Jafari

Parwana described Sprint 5 as both challenging and enjoyable.

She explained that one of the main challenges was improving the website for mobile devices.

The team had to return to previously completed pages and adjust:

- CSS
- Navigation
- Buttons
- Page layouts
- Responsive behavior

She also explained that the notification feature needed more than one version before the team achieved the result they wanted.

She said that each step had challenges, but the team was able to solve them.

---

## 👩‍💻 Nargis Bunyadi

Nargis said that working on the project was an enjoyable experience.

She especially appreciated:

- Good communication
- Teamwork
- Cooperation between the developers
- Finishing work on time
- Supporting each other during the project

She said that the strong communication and partnership helped the team complete the project successfully.

---

## ⚠️ Most Difficult Part

The developers agreed that one of the most difficult parts of the final Sprint was improving previously completed pages for mobile and tablet views.

This required:

- Returning to existing code
- Finding the correct CSS and page sections
- Adjusting layouts
- Changing buttons and navigation
- Testing the same pages again
- Making sure the website still worked properly on desktop

The team completed these changes successfully.

---

## 🤝 Team Experience

The team reflected positively on the overall project.

The members appreciated:

- Working together
- Supporting each other
- Good communication
- Solving problems as a team
- Learning from each other
- Completing the project together

The team agreed that cooperation and communication were important parts of the project's success.
