### **Nargis Bunyadi (Developer – Frontend)**

- Returned to the meeting after being absent the previous day due to illness.
- Worked on the frontend for **Edit Listing** and **Mark as Sold**.

For **Edit Listing**, she:

- Created the Edit Listing page.
- Added fields for:
  - Clothing name
  - Category
  - Price
  - Size
  - Condition
  - City
  - Description
- Allowed sellers to keep the current photo or choose a replacement photo.

For **Mark as Sold**, she:

- Added the Mark as Sold button.
- Added a confirmation message before sending the request.
- Added **Available** and **Sold** labels to clothing cards.
- Added loading, success, and error messages.
- Temporarily disabled buttons during requests to prevent repeated actions.
- Updated Size and Condition options to match the original selling form.
- Shared the frontend files with Parwana for backend connection and testing.
- Mentioned that final testing will continue to confirm that changes remain correctly after refreshing the page.

---

### **Parwana Jafari (Developer – Backend)**

- Continued backend work for **Edit Listing** and **Mark as Sold**.

For **Edit Listing**, she:

- Added backend functionality that allows sellers to edit their own listings.
- Made sure updated information is saved in the database.
- Made sure saved changes are displayed correctly.

For **Mark as Sold**, she:

- Added functionality that allows sellers to mark their own clothing items as sold.
- Changed the product status from **Available** to **Sold**.
- Connected the status change with the listing data.

She also continued working on the **Seller Dashboard**, where sellers can see their listings as:

- Active
