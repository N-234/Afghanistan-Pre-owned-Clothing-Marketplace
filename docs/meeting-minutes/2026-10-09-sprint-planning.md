## Meeting Purpose

To explain and clarify the Sprint 1 requirements, review the main User Stories, and make sure the developers understand what they need to work on during Sprint 1.

---

## Sprint 1 Focus

Sprint 1 will focus on the basic functionality of the website.

The main Sprint 1 requirements include:

- Creating a user account
- Login and logout
- Displaying recently added clothes
- Clothing categories
- Password security
- A simple and easy-to-understand user interface

By the end of Sprint 1, users should be able to create an account, log in, and explore the basic parts of the website.

---

## Meeting Summary

**Hajar Khawari (Scrum Master):**  
Opened the meeting and explained the main focus and expected work for Sprint 1.

She explained the basic features that should be included in Sprint 1 and asked the developers whether the requirements were clear and whether they understood what they needed to work on.

---

**Sara Qateh (Product Owner):**  
Explained several important User Stories and requirements that should be considered during Sprint 1.

She clarified that:

- A user should be able to create an account to buy or sell pre-owned clothes.
- A registered user should be able to log in securely and access their personal account.
- Only correct login credentials should allow access.
- Buyers should be able to see recently added clothes.
- Buyers should be able to view clothes by category.
- Buyers should be able to search for clothing items by name or keyword.
- Password protection is an important requirement for Sprint 1.

Sara also mentioned that Sprint 2 requirements would be discussed later.

---

**Nargis Bunyadi (Developer):**  
Confirmed that the Sprint 1 requirements were clear and that the developers understood the expected work.

---

**Parwana Jafari (Developer):**  
Asked for clarification about how clothing categories should work on the homepage.

She asked whether clothes such as dresses, shirts, and pants should appear as separate categories or whether all clothes could appear together with search and filtering options.

The Product Owner clarified that the homepage can display available clothing items, while search and filtering options should allow users to find specific types of clothes.

Parwana confirmed that the explanation was clear.

---

## Key Decisions

- Sprint 1 will focus on the basic functionality of the website.
- Account creation, login, logout, recently added clothes, and clothing categories will be included.
- Password security must be considered during development.
- The user interface should remain simple and easy to understand.
- Search and filtering should help users find specific clothing items.
- Sprint 2 requirements will be discussed after Sprint 1.
