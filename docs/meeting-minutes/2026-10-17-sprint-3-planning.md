## Product Owner Requirements – Sara Qateh

Before the meeting ended, Sara gave additional details about the Sprint 3 requirements.

### View My Listings

Sara explained that sellers should be able to see all of their posted clothing listings in one place.

The seller dashboard should show listing status, including:

- Active listings
- Sold listings
- Removed listings

This will help sellers manage their clothing listings more easily.

### Edit Listing

Sara confirmed that sellers should be able to update their own clothing listings.

This allows sellers to correct or change listing information when needed.

### Mark as Sold

Sara explained that sellers should be able to mark an item as sold when it is no longer available.

When this happens, the product status should change from:

**Available → Sold**

This helps buyers understand that the clothing item is no longer available.

### Save Clothes

Sara confirmed that buyers should be able to save clothing items they like so they can return to them later.

### Contact Seller

Sara explained that buyers should be able to contact the seller about a specific clothing item.

This will allow buyers to ask questions before deciding whether to purchase the item.

Sara asked the development team to make sure these requirements are followed during Sprint 3.
