## 🎯 Sprint Overview

Sprint 2 focused on improving product search and seller listing functionality.

The main goal was to help buyers find suitable clothes more easily and allow sellers to create complete listings with photos and detailed product information.

The Sprint also focused on validation, performance, frontend/backend integration, and final testing.

## ✨ Additional Improvement

During Sprint 2, the team also added a **Forgot Password and Reset Password** feature.

This feature was not part of the original Sprint 2 backlog but was added as an extra improvement.

The completed flow allows users to:

▪ Request a password reset  
▪ Receive a reset link  
▪ Enter a new password  
▪ Confirm the new password  
▪ Log in again using the updated password  

The feature was demonstrated successfully during the Sprint 2 Review.
