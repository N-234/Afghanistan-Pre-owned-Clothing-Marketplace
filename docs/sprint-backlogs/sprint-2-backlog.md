## Sprint 2 Tasks

### Backend and Primary Implementation Tasks – Parwana Jafari

#### 1. Search and Filtering Support

▪ Connect Search functionality with clothing listing data  
▪ Support Size and Price Filter logic  
▪ Retrieve matching products based on selected filters  
▪ Support frontend filtering with backend data  

#### 2. Clothing Condition

▪ Add clothing condition to product information  
▪ Support condition options such as New, Like New, Good, and Used  
▪ Save the selected condition with the clothing listing  
▪ Retrieve condition information for display  

#### 3. Product Information and Database Integration

▪ Store required product information in the database  
▪ Support price, size, condition, and description data  
▪ Retrieve product information correctly  
▪ Connect product information with clothing listings  

#### 4. Input Validation

▪ Validate required listing fields  
▪ Prevent incomplete required information from being submitted  
▪ Check listing information before publishing  
▪ Provide validation when required information is missing  

#### 5. Product Photo Backend Support

▪ Support uploaded product photos  
▪ Connect uploaded images with the correct clothing listing  
▪ Support image information needed for product display  

---

### Frontend and Interface Tasks – Nargis Bunyadi

#### 6. Search for Clothes

▪ Create the Search interface  
▪ Allow users to search clothing items by name or keyword  
▪ Display matching clothing items  
▪ Show an appropriate message when no matching result is found  

#### 7. Size and Price Filters

▪ Add Size Filter options  
▪ Add Price Filter options  
▪ Display products based on selected filters  
▪ Make filters clear and easy to use  
▪ Support clearing selected filters  

#### 8. Upload Product Photos

▪ Add photo upload to the clothing listing form  
▪ Allow sellers to select clothing images  
▪ Display uploaded photos with clothing listings  
▪ Connect the photo upload interface with listing functionality  

#### 9. Product Information Interface

▪ Add fields for required clothing information  
▪ Organize product details clearly  
▪ Display product information to buyers  
▪ Support the listing preview and publishing process  

#### 10. Performance and Interface Checking

▪ Check the main website flow during normal use  
▪ Review page behavior and responsiveness  
▪ Check the interface on smaller screens  
▪ Identify interface issues that may affect normal use
