## Sprint 4 Tasks

### 👩‍💻 Backend and Primary Implementation Tasks – Parwana Jafari

#### 1. Report Listing Backend Support

▪ Support report submission from users  
▪ Store the report reason  
▪ Connect the report with the correct clothing listing  
▪ Save submitted reports for administrator review  

#### 2. Review Reports

▪ Allow administrators to view submitted reports  
▪ Retrieve the related clothing listing information  
▪ Allow administrators to inspect reported listings  
▪ Support removing inappropriate content when necessary  

#### 3. Manage Users

▪ Allow administrators to view registered user accounts  
▪ Support account management functionality  
▪ Allow administrators to deactivate accounts that violate platform rules  
▪ Update user account status correctly  

#### 4. Administrator Access

▪ Restrict administrator functions to authorized administrators  
▪ Prevent normal users from accessing administrator pages or functions  
▪ Check administrator access before allowing management actions  

#### 5. Backend Integration

▪ Connect report data with administrator functions  
▪ Connect user account data with user management functionality  
▪ Support listing status information for monitoring  
▪ Make sure administrator actions update stored data correctly  

---

### 👩‍💻 Frontend and Interface Tasks – Nargis Bunyadi

#### 6. Report Listing Interface

▪ Add a Report Listing option for users  
▪ Create a simple report form  
▪ Allow users to enter a reason for the report  
▪ Connect the report form with report submission functionality  

#### 7. Monitor Listings

▪ Create an interface for administrators to view clothing listings  
▪ Display listing information clearly  
▪ Show listing status such as Available, Sold, and Removed  
▪ Make listing monitoring easy to use  

#### 8. Administrator Interface Support

▪ Organize report information clearly  
▪ Organize user and listing information for administrator use  
▪ Keep administrator functions easy to find  
▪ Connect frontend administrator pages with backend functionality
