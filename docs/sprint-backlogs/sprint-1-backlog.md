Sprint 1 focuses on:

▪ Creating user accounts  
▪ Login and Logout functionality  
▪ Recently Added Clothes  
▪ Clothing Categories  
▪ Password Security  
▪ A simple and user-friendly interface

## Sprint 1 Tasks

### Backend and Primary Implementation Tasks – Parwana Jafari

#### 1. User Account Setup

▪ Create account functionality  
▪ Connect user registration with the backend  
▪ Store user information in the database  
▪ Check required registration information  
▪ Prevent duplicate email registration  

#### 2. Login and Logout

▪ Implement Login functionality  
▪ Verify user credentials  
▪ Manage user sessions  
▪ Implement Logout functionality  
▪ Connect Login with stored user account information  

#### 3. Password Security

▪ Protect user passwords using password hashing  
▪ Prevent passwords from being stored as plain text  
▪ Require authentication for protected user functions  

#### 4. Database and Backend Integration

▪ Connect the backend with the database  
▪ Support user account data  
▪ Support clothing listing data needed for the Homepage  
▪ Connect backend functionality with frontend pages  

---

### Frontend and Interface Tasks – Nargis Bunyadi

#### 5. Signup Page

▪ Create the Signup page  
▪ Add required registration fields  
▪ Create clear navigation between Signup and Login  
▪ Connect the Signup interface with account creation functionality  

#### 6. Login Page

▪ Create the Login page  
▪ Add email and password fields  
▪ Provide clear navigation between Login, Signup, and Homepage  
▪ Add the My Account interface  

#### 7. Recently Added Clothes

▪ Create the main clothing display on the Homepage  
▪ Add a Recently Added Clothes section  
▪ Display basic product information  
▪ Organize newer clothing listings clearly  

#### 8. Clothing Categories

▪ Add clothing categories to the interface  
▪ Include categories such as Dresses, Shirts, Trousers, Jackets, and Traditional Clothes  
▪ Make categories easy for users to find and explore  

#### 9. Simple User Interface

▪ Create a simple and clear website layout  
▪ Keep major functions easy to find  
▪ Create clear navigation between main pages  
▪ Maintain consistent styling across the website
