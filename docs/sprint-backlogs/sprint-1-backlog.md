# Sprint 1 Backlog

**Project:** Afghan Girls' Pre-Owned Clothes Marketplace  
**Sprint:** Sprint 1  
**Duration:** October 9-11, 2026  
**Sprint Goal:** Build the foundation of the marketplace and allow users to access and explore the system.  
**Total Story Points:** 28  
**Sprint Status:** ✅ Completed  

---

## 🎯 Sprint Overview

Sprint 1 focused on building the basic foundation of the Afghan Girls' Pre-Owned Clothes Marketplace.

The main goal was to make sure users could create accounts, log in securely, browse recently added clothes, view clothing categories, and use a simple and clear interface.

This Sprint also included the basic backend, database connection, password security, and frontend/backend integration needed for future Sprints.

## Task Breakdown by Feature

### US-001: Create Account – 5 Story Points

**Assigned to:** Parwana Jafari  
**Status:** Completed

**What it does:**  
Allows a new user to create an account so they can use the marketplace to buy or sell pre-owned clothes.

**Acceptance Criteria:**

- Registration requires valid information
- Account is created successfully
- Duplicate email is rejected

**Tasks:**

- Connect account creation to the backend
- Connect signup information to the database
- Store new user account information
- Check user information before account creation
- Support secure password handling
- Create the signup page
- Add the required signup form fields
- Connect the signup page with the website interface
