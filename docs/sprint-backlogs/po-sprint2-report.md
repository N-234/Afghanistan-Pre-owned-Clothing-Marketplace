## ✨ Additional Improvement

During Sprint 2, the team also added a **Forgot Password and Reset Password** feature.

This feature was not part of the original Sprint 2 backlog but was completed as an additional improvement.

The completed flow allows users to:

▪ Request a password reset  
▪ Receive a reset link  
▪ Enter a new password  
▪ Confirm the new password  
▪ Log in again using the updated password  

The feature was demonstrated successfully during the Sprint 2 Review.
