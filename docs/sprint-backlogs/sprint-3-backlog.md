## 🎯 Sprint Goal

Give sellers more control over their clothing listings and allow buyers to save clothes and communicate with sellers.

Sprint 3 focuses on:

▪ View My Listings  
▪ Edit Listing  
▪ Mark as Sold  
▪ Save Clothes  
▪ Contact Seller  
▪ Data Reliability

## Sprint 3 Tasks

### Backend and Primary Implementation Tasks – Parwana Jafari

#### 1. Edit Listing

▪ Allow sellers to edit their own clothing listings  
▪ Update listing information in the database  
▪ Save edited listing information correctly  
▪ Make sure updated information is displayed after saving  

#### 2. Mark as Sold

▪ Allow sellers to mark their clothing item as sold  
▪ Change the product status from Available to Sold  
▪ Save the updated listing status  
▪ Display the updated status correctly  

#### 3. Contact Seller Backend Support

▪ Support messages connected to a specific clothing listing  
▪ Connect buyer messages with the correct seller  
▪ Store message information correctly  
▪ Allow sellers to receive and view messages  

#### 4. Data Reliability

▪ Store user and product information correctly  
▪ Retrieve saved information when needed  
▪ Reduce the risk of unexpected data loss  
▪ Check that updated listing information remains available  

#### 5. Seller Listing Backend Support

▪ Retrieve listings belonging to the logged-in seller  
▪ Support Active, Sold, and Removed listing information  
▪ Connect seller listing data with the Seller Dashboard  

---

### Frontend and Interface Tasks – Nargis Bunyadi

#### 6. View My Listings

▪ Create the Seller Dashboard interface  
▪ Display the seller's own clothing listings  
▪ Organize Active, Sold, and Removed listings clearly  
▪ Make listing management easy to access  

#### 7. Save Clothes

▪ Add a Save option for clothing items  
▪ Allow buyers to save clothes they like  
▪ Allow buyers to remove items from Saved Clothes  
▪ Display saved items in the user's account  

#### 8. Contact Seller Interface

▪ Add a Contact Seller option to clothing listings  
▪ Create a simple message interface  
▪ Connect the message to the selected clothing item  
▪ Make the communication flow clear for buyers  

#### 9. Seller Dashboard Interface

▪ Display listing information clearly  
▪ Provide access to listing management functions  
▪ Show listing status to the seller  
▪ Keep the interface simple and easy to use
